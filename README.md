# AI-powered Film Photography Contest Management Platform

**Đề tài:** Nền tảng tổ chức và quản lý cuộc thi nhiếp ảnh phim tích hợp trí tuệ nhân tạo.

## Tình trạng tài liệu

> Bản tài liệu Requirements đang chuẩn bị đưa lên repository. **Chưa hoàn thành việc nhập toàn bộ bộ hồ sơ.** Không coi các yêu cầu là đã được phê duyệt hay triển khai.

## Cấu trúc thư mục được giảng viên yêu cầu

```text
Project/
├── Docs/       # Problem, Context, Requirements, Entity, Traceability, Test, Feasibility
├── BE/         # Backend README và mã nguồn
├── FE/         # Frontend README và mã nguồn
├── Skills/     # Bộ SKILL.md
├── README.md
└── Check-list.md
```

## Tài liệu cần đưa vào

- `Docs/02-requirements/`: các Functional và Non-functional Requirements tách file Markdown.
- `Docs/03-domain/`: entity, data dictionary, ERD và business rules.
- `Docs/04-traceability/`: ma trận truy vết Requirement–Jira–Test.
- `Docs/05-quality/`: happy/unhappy case, test strategy và test matrix.
- `Docs/06-feasibility/`: đánh giá khả thi, công sức và rủi ro.
- `BE/README.md` và `FE/README.md`.
- `Skills/`: hướng dẫn quy trình phân tích, thiết kế, kiểm thử và phát triển.

**Lưu ý:** Nội dung triển khai chính thức phải được đối chiếu với đề tài giảng viên và được nhóm review.
