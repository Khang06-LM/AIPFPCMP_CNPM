# Thuật ngữ sử dụng thống nhất

| Thuật ngữ | Ý nghĩa trong dự án |
|---|---|
| Film photography | Ảnh chụp trên phim vật lý, nộp lên hệ thống bằng ảnh scan |
| Film stock | Hãng/dòng phim analog (ví dụ mã sản phẩm phim) |
| Film roll | Một cuộn phim của Participant |
| Film frame | Một khung hình cụ thể trên cuộn, có số frame |
| ISO | Độ nhạy sáng phim khai báo, không đồng nhất bằng chứng độ chân thực |
| Film lab | Đơn vị tráng phim (đóng vai trò metadata, chưa là actor login) |
| Contact sheet | Bảng in/tổng hợp khung hình được dùng làm đối chứng tùy chọn |
| Negative | Âm bản phim, có thể được tải làm bằng chứng |
| Submission | Bài dự thi gửi vào một cuộc thi/hạng mục |
| Enrollment | Đăng ký tham gia cuộc thi, khác với bài dự thi |
| Validation | Kiểm tra rule máy như hạn, định dạng, metadata |
| Review | Quyết định của người kiểm duyệt đối với bài nộp |
| Judge | Giám khảo có phân công theo category/round |
| CriterionScore | Điểm cho một tiêu chí bởi một giám khảo trong một lượt chấm |
| RankingSnapshot | Bảng tổng hợp đã khóa phiên bản phục vụ công bố |
| Digital Archive | Kho dữ liệu tác phẩm đủ điều kiện công khai và metadata liên quan |
| AC | Acceptance Criteria, điều kiện nghiệm thu |
| TC | Test Case, kịch bản kiểm thử có đầu vào/expected/actual |
| BR | Business Rule, quy tắc nghiệp vụ |
| FR / NFR | Functional / Non-functional Requirements |
| MVP | Bản nhỏ nhất demo được quy trình chính nhưng không bỏ yêu cầu gốc nếu GV không đồng ý |
| PoC / Spike | Thử nghiệm nhỏ để chứng minh khả thi hoặc xác định rủi ro |
| TBD | Chưa được quyết định/xác nhận |
| Source G / P / D | Giảng viên / Kế hoạch nhóm / Nhóm phân tích đề xuất |
