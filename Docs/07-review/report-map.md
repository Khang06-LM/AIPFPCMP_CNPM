# REPORT-MAP — Ghép Markdown thành báo cáo 6 phần

Theo kế hoạch nhóm [P], báo cáo gồm: I Giới thiệu, II Quản lý dự án, III SRS, IV Thiết kế, V Kiểm thử, VI Phát hành. Các file Markdown là **source of truth có thể review**; khi xuất báo cáo phải dẫn đúng version.

| Phần báo cáo | Lấy nội dung từ |
|---|---|
| I — Giới thiệu / Problem / Context | `Docs/00-overview/` |
| II — Quản lý dự án | `Docs/01-governance/`, `Docs/06-feasibility/` và lịch Jira thực |
| III — SRS | `Docs/02-requirements/`, `Docs/04-traceability/`, flow diagrams |
| IV — Thiết kế | `Docs/03-domain/`, BE/FE README, OpenAPI khi có |
| V — Kiểm thử | `Docs/05-quality/` + **actual test results**, không chỉ test design |
| VI — Phát hành | BE/FE README với lệnh thực, staging URL, release tag khi có |

**Chỉ đưa vào báo cáo “Đã triển khai” nếu có bằng chứng thực.**
